# 图元详情页设计

**目标**

在现有 `#/primitives` 图元总览页基础上，为每个图元提供独立详情页。用户可以点击任意图元进入 `#/primitives/:id`，查看更大的预览、参数说明、适用场景，并通过滑块实时调整参数。

**范围**

- 保留图元总览页
- 新增图元详情页路由
- 所有当前展示的图元都支持详情页
- 详情页以滑块调参为主，必要时允许少量开关
- 参数变化后实时重建几何体并更新构造代码展示

**架构**

- 抽离一份共享图元目录数据，统一描述图元名称、默认参数、控件配置、中文说明、构造代码和几何创建函数
- 总览页和详情页都读取同一份图元目录，避免两套数据源
- 总览页继续使用共享 renderer 的多区域裁剪渲染
- 详情页使用单独 renderer，专注于单个图元的实时调参
- 主路由从静态映射升级为“静态路由 + primitives 动态详情路由解析”

**页面结构**

总览页：
- 图元卡片网格
- 卡片预览
- 名称、示例代码、简介
- 点击后跳转到详情页

详情页：
- 返回图元总览
- 图元标题、简介、当前构造代码
- 大预览区
- 参数滑块面板
- 每个参数的中文解释
- 固定输入说明，例如路径、轮廓点、字体、参数函数
- 使用场景和学习提示

**参数策略**

- 基础图元直接映射到构造函数参数
- 特殊图元允许“构造参数 + 示例生成参数”混合展示
- `LatheGeometry`、`TubeGeometry`、`ExtrudeGeometry`、`ParametricGeometry`、`TextGeometry`、`PolyhedronGeometry` 会明确标注哪些是示例辅助参数，哪些是 Three.js 原生构造参数

**验证**

- 运行 `npm run build`
- 手工检查 `#/primitives` 与 `#/primitives/:id`
- 手工检查滑块拖动后几何体是否即时更新
